Los diferentes modelos de RPi tienen diferentes opciones de memoria prestablecida, van desde 1GB hasta 16GB:
- La memoria de los RPi no se puede aumentar después. 
- Niveles típicos de uso:
	- **1GB:** Servidores / Cargas de trabajo mínimas
	- **2GB**: Proyectos básicos & aprendizaje (Donde casi todos comenzarán)
	- **4G:** Es un punto de comienzo sólido si planea utilizarlo como Escritorio.
	- **8GB:** Navegación web y apps más pesadas.
	- **16GB:** Cargas de trabajo muy pesadas y proyectos avanzados.

La Raspberry sola no funciona, necesitas algunos accesorios para empezar a usarlo, mínimo necesitarás lo siguiente:
- Adaptador de corriente.
- Tarjeta MicroSD
- Teclado, ratón y un micro HDMI *(es más fácil para principantes)*
- La SD se usa para flashear un SO dentro de ella para poder iniciar el RPi.
La velocidad de la SD puede mejorar o empeorar el sistema, ya que ahí correrá el el SO. Se pueden conseguir ya booteadas, pero la instalación es fácil y la gente prefiere hacerlos ellos mismos. 
---
### Cómo instalar un sistema operativo en la SD
- A menos que tenga una preferencia en particular, el SO por defecto para Pi se llama Raspberry Pi OS (antes conocido como Rasbpian)
- Incluye un ambiente de escritorio, herramientas de desarrollo para navegación web, y herramientas útiles. 
- Hay muchas imágenes de SO disponibles, como distribuciones de Linux Populares que varias de ellas se van a usos específicos.
Este proceso es diferente al tradicional, acá lo que se hará es escribir una imagen de un sistema operativo directamente en una microSD. Una buena herramienta para comenzar en esto es "Raspberry Pi Imager".
